### Where the real error field came from (the evidence round 1 lacked)

No ImmyBot credentials exist in this environment (no `IMMY_*` env vars; the instance swagger at
`https://mspbotsai.immy.bot/swagger/v1/swagger.json` answers `401 PrincipalMissing`). The
instance's web app shell, however, is public: `GET https://mspbotsai.immy.bot/` serves the SPA,
whose single bundle `/assets/index-CjW3kQrC.js` (17,045,499 bytes, fetched 2026-11-10) contains
ImmyBot's own client for this exact record:

- `AdhocScriptRunsApiRoutes`: `Base=api/v1/adhoc-script-runs`, `GetDx=api/v1/adhoc-script-runs/dx`,
  `GetById=api/v1/adhoc-script-runs/{id}`.
- `AdhocScriptRunsApi.getById(id, queries)` calls `$get(/api/v1/adhoc-script-runs/${id}, {params: queries})`.
- `AdhocScriptRunDetailPanel` loads `adhocScriptRunsApi.getById(props.id, {createdAt: createdAtIso})`
  and computes `hasErrors` from `detail.errorsJson`: `JSON.parse(raw)`; an array means
  `length > 0`, any other parsed value means `!= null`, an unparsable string counts as an error.
  It renders the "Errors" panel from that same `errorsJson`.
- The `/dx` grid's column list (`AdhocScriptRunTable`) is `status, requestedByUserName,
  requestingClientId, mcpSessionName, initiatedByMcp, scriptName, scriptText, output,
  computerName, tenantName, createdAt, startedAt, completedAt, durationMs, scriptContext,
  userAgent, consoleTextBytes, consoleTextTruncated, consoleTextLastUpdatedAt` -- no error field.
  `errorsJson` occurs exactly twice in the bundle, both inside the detail panel.
- The status enum (`AdhocScriptRunStatus`: Pending=0, Running=1, Completed=2, Failed=3, ...)
  matches `_RUN_STATUS` (`scripts.py:64`) unchanged.

This explains QA-NIGHT's run `add42035-7795-46ac-b529-2c8591f23d22`: the `/dx` row carries none
of round 1's four guessed names, and the error text lives in `errorsJson` on the per-run record.
